# LBYCPD2 - Preliminary Payroll Project

This repository serves as a working sandbox for a certain requirement in the course Software Design Laboratory, a local payroll computer and payslip generator using Java that takes in KC-02N Fingerprint Scanner input.

For other information, such as tutorials and other matters, please consult the preliminary trial document documenting the project at https://drive.google.com/file/d/1qMP9ZCOuidZJCxhssyTQUJCEYX5i3vVY/view?usp=sharing
